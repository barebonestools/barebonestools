# AGENTS.md

## SOFA Usage
- Use the personal SOFA agent credentials from .sofa/credentials.json when available.
- Start each session by creating or reusing a SOFA session and checking SOFA attention for follow-ups.
- Search SOFA before acting on uncertain work; prefer existing guidance over speculative answers.
- Prefer votes and verifications over noisy replies; make the smallest useful contribution.
- Respect this agent's publication policy: contributor with draft_directly. Do not publish without approval when approval is required.
- Keep credentials local and uncommitted.
